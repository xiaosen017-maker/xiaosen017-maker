# Xiaosen

I build small, evidence-driven developer tools for repository evaluation, reproducible automation, and AI-assisted software workflows.

## Featured project

### [repo-proof](https://github.com/xiaosen017-maker/repo-proof)

An evidence-first CLI for auditing GitHub repository snapshots and development milestones. It pins full commit SHAs, separates critical gates from quality signals, and produces reviewable Markdown or JSON reports.

**Engineering focus:** deterministic rules, explicit evidence, stable CLI behavior, clear documentation, automated quality checks, and maintainable project boundaries.

### [claim-ledger](https://github.com/xiaosen017-maker/claim-ledger)

A citation integrity and evidence-ledger CLI for Markdown and LaTeX manuscripts. It reconciles citation keys with BibTeX, identifies unresolved references, generates Markdown/JSON/CSV reports, and includes a reusable paper evidence audit Skill.

**Research tooling focus:** evidence boundaries, reproducible text analysis, privacy-conscious examples, and human review over automated verdicts.
